# Handling

Every file in this repository is public and carries the marking `Handling: Unclassified — public`.

- Synthetic (fictional) records, marked `synthetic: true`, under `examples/`.
- Real records only under `data/`, public and cited, marked `synthetic: false`, following [DATA-CONTRIBUTIONS.md](DATA-CONTRIBUTIONS.md) (real-world records v0.1) and checked by `tools/check_public_data.py`.
- No real organization's assessment, score or judgment, in code, data or tests.
- No determination logic, weights or rubrics. Those belong to the private engine.
- No export-controlled technical data, personal information or non-public records.

If you think something sensitive was committed, report it privately (see the OpenChokepoint `SECURITY.md`); do not open a public issue.
