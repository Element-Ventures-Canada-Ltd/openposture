# Deferred Ledger

Public record of bounty entries under BOUNTIES.md. Maintainers update this file
in the pull request that merges the qualifying work. Amounts are nominal, in
Canadian dollars. An entry is a record of accepted work, not a promise of
payment before a Funding Event.
